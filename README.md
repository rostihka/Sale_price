# Price Monitor — моніторинг цін з сповіщеннями в Telegram

Щодня (за розкладом GitHub Actions) скрипт перевіряє ціни за посиланнями з `config.json`
і надсилає повідомлення в Telegram, якщо ціна впала.

## ⚠️ Перше, що треба зробити: перевипустити токен бота

Токен, який був показаний у чаті з Claude, вже "засвітився" в переписці — це небезпечно
зберігати. Перед тим як щось налаштовувати:

1. Відкрий Telegram, знайди **@BotFather**.
2. Напиши `/mybots` → обери свого бота → **Bot Settings** → **Revoke current token**.
3. Скопіюй новий токен — саме його вставлятимеш у GitHub Secrets (крок 4 нижче), а не в код.

## 1. Створи приватний репозиторій на GitHub

Завантаж туди всі файли з цього проєкту, зберігаючи структуру папок (включно з
`.github/workflows/price-check.yml`).

## 2. Дізнайся свій Telegram chat_id

1. Знайди свого бота в Telegram (за іменем, яке ти йому дав через BotFather) і натисни **Start**
   (або напиши будь-яке повідомлення).
2. Відкрий у браузері:
   `https://api.telegram.org/bot<ТВІЙ_ТОКЕН>/getUpdates`
3. У відповіді (JSON) знайди `"chat":{"id": 123456789, ...}` — це і є твій `chat_id`.

Якщо відповідь порожня — напиши боту ще одне повідомлення і онови сторінку.

## 3. Додай секрети в GitHub

У репозиторії: **Settings → Secrets and variables → Actions → New repository secret**

- `TELEGRAM_BOT_TOKEN` — новий токен бота
- `TELEGRAM_CHAT_ID` — твій chat_id з кроку 2

## 4. Розклад перевірки

За замовчуванням workflow запускається раз на день о 08:00 UTC (файл
`.github/workflows/price-check.yml`, рядок `cron: "0 8 * * *"`). Зміни цей рядок під себе,
наприклад:

- `"0 6 * * *"` — щодня о 06:00 UTC
- `"0 6,18 * * *"` — двічі на день

Також можна запустити перевірку вручну: вкладка **Actions** → **Price Monitor** →
**Run workflow**.

## 5. Як влаштовані критерії сповіщень

Бот сповіщає при **будь-якому** зменшенні ціни і додає позначку залежно від глибини падіння:

- 🔻 < 10%
- 📉 10%+
- 📉 15%+
- 🔥 20%+
- 🔥 > 25%

Логіка — у функції `classify_drop()` у `monitor.py`, якщо захочеш змінити пороги.

## 6. Що саме відстежується зараз (`config.json`)

| id | Що це | Логіка |
|---|---|---|
| `comfy_galaxy_a17` | Товар на comfy.ua | Бере ціну з метатегу сторінки |
| `auto_ria_bolt_ev_search` | Пошукова видача Chevrolet Bolt EV на AUTO.RIA | Бере **мінімальну** ціну серед усіх оголошень у видачі |

## 7. Як додати відстеження конкретного оголошення на AUTO.RIA

Ти казав, що хочеш стежити і за окремими оголошеннями теж. Просто додай новий об'єкт
у масив `items` в `config.json`, вказавши тип `auto_ria_listing` і посилання на конкретне
оголошення (не на сторінку пошуку):

```json
{
  "id": "auto_ria_listing_39317251",
  "name": "Bolt EV 2022, Конотоп",
  "type": "auto_ria_listing",
  "url": "https://auto.ria.com/uk/auto_chevrolet_bolt-ev_39317251.html"
}
```

`id` має бути унікальним для кожного елемента (за ним зберігається історія цін).

## 8. Як додати товар з іншого магазину

- Якщо у сайту в коді сторінки є метатег `<meta property="product:price:amount" content="...">`
  (як у comfy.ua) — використовуй тип `comfy_product`, воно спрацює однаково для будь-якого
  сайту з таким метатегом (це поширений стандарт Open Graph для товарів).
- Якщо сайт унікальний і такого метатегу немає — напиши мені посилання на товар, і я додам
  окрему функцію парсингу під конкретну верстку сайту.

## 9. Локальне тестування (не обов'язково)

```bash
pip install -r requirements.txt
export TELEGRAM_BOT_TOKEN="твій_токен"
export TELEGRAM_CHAT_ID="твій_chat_id"
python monitor.py
```

Перший запуск лише зафіксує стартові ціни (без сповіщень — нема з чим порівнювати).
Наступні запуски вже порівнюватимуть і сповіщатимуть про падіння.

## 10. Важливо знати про AUTO.RIA

Сторінки AUTO.RIA іноді захищені від автоматичних запитів (антибот-захист). Якщо скрипт
почне видавати помилки завантаження саме для auto.ria (в логах Actions), можливі варіанти:
- додати затримку між запитами (вже є, 2 сек);
- запускати перевірку рідше (не частіше 1 раз/день, як і задумано);
- якщо блокування стабільне — знадобиться інший підхід (наприклад, headless-браузер),
  напиши мені, і я адаптую скрипт.

## 11. Обмеження

- `state.json` (історія цін) зберігається прямо в репозиторії — тому тримай репозиторій
  **приватним**, якщо не хочеш ділитись цінами публічно.
- AUTO.RIA також має власну вбудовану функцію "Підписатись на цей пошук" (кнопка внизу
  сторінки пошуку) — вона сповіщає про нові оголошення, але не про зміну ціни, тому це
  не замінює цей інструмент.
